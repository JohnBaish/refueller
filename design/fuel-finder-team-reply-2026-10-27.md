Dear Sir/Madam,
Thank you for your email.

The CSV file is updated twice daily, so you can use these publication times to schedule your data refreshes.

There is no requirement under the Fuel Finder regulations for your website to make API requests every five minutes. The five-minute requirement relates to how frequently the Fuel Finder service updates its API following a reported price change.

We would recommend clearly displaying when each fuel price was last updated so users are aware of how current the information is.

Please note that use of the data remains subject to the Fuel Finder Fair Use policy.

If you have any further questions, please feel free to contact us.
