A 403 Forbidden error indicates that access to the requested resource is being denied. This typically occurs for one of the following reasons:

- The request is being made from an IP address outside the UK
- Invalid or missing authentication credentials, such as the client ID, client secret or access token
- Incorrect endpoint or request configuration

If your service is located outside the UK and requires whitelisting, please provide the following details so that we can investigate and, where appropriate, raise a request with the Fuel Finder Infrastructure team:

- Organisation name
- Type (Information Recipient or MFT)
- Stated reason for access, if applicable
- Location of the affected service/server
- Single static public outbound IP address to be whitelisted

Once we receive this information, we will review the details and progress your request accordingly.
